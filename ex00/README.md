# Safa's Personal Portfolio

## About the Project

This project is a personal portfolio website created to introduce myself, showcase my skills and coursework projects, and provide contact information.

The portfolio uses a dark plum theme and a calm dusty pink theme that users can switch between interactively.

## Features

- **Home:** A welcome section introducing the portfolio.
- **About Me:** A short introduction and profile picture.
- **Skills:** A list of technical skills.
- **Projects:** A showcase of projects completed during the Web Piscine.
- **Hobbies:** A list of personal interests.
- **Contact:** Email, LinkedIn, and a contact form.
- **Theme Switcher:** A JavaScript button that switches between dark and light pink themes.
- **Responsive Design:** CSS media queries adapt the layout to smaller screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the project repository.
2. Open the `ex00` directory.
3. Open `index.html` in a web browser.
4. Click the **Change Theme** button to switch between themes.
